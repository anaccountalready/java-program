# Fivechese项目重构说明

## 概述
本项目是一个基于Java Swing的五子棋游戏，支持本地和网络对战功能。本次重构主要完成了单例模式的应用、安全问题修复和代码优化。

## 一、单例模式重构

### 1.1 已实现单例模式的类
- **BackGroundMusic.java** - 背景音乐播放类
- **ChessPanel.java** - 游戏主面板类
- **Chatpanl.java** - 聊天面板类
- **Control.java** - 游戏控制类
- **Model.java** - 游戏数据模型类
- **NetHelper.java** - 网络通信类
- **NetPanel.java** - 网络控制面板类

### 1.2 单例模式实现方式
采用**饿汉式单例模式**，在类加载时就创建实例，确保线程安全：
```java
private static ClassName instance = new ClassName();
private ClassName() {}  // 私有构造函数
public static ClassName getInstance() {
    return instance;
}
```

## 二、安全问题修复

### 2.1 数据安全修复 (Model.java)
1. **封装数据访问**
   - 将`list`从`public static`改为`private`
   - 通过`getList()`返回不可修改的列表视图：`Collections.unmodifiableList(list)`
   - `getData()`返回数组副本而非内部引用，防止外部修改

2. **边界检查**
   - `putChess()`方法添加数组边界检查：`row >= width || row < 0 || col < 0 || col >= width`
   - `back()`方法添加列表大小检查：`list.size() < 2`，避免空列表异常

3. **线程安全**
   - 所有修改数据的方法添加`synchronized`关键字，确保多线程环境下的数据一致性

### 2.2 网络通信安全修复 (NetHelper.java)
1. **输入验证**
   - 使用正则表达式验证消息格式：`CHESS_PATTERN`, `CHAT_PATTERN`, `REBACK_PATTERN`
   - 对棋子位置进行范围验证：`row < 0 || row >= Model.width || col < 0 || col >= Model.width`

2. **消息过滤**
   - 添加`filterMessage()`方法，对HTML特殊字符进行转义：`<`, `>`, `&`
   - 限制消息长度：`MAX_MESSAGE_LENGTH = 1000`

3. **资源管理**
   - 添加`closeResources()`方法，确保Socket、流等资源正确关闭
   - 添加`isRunning`标志，优雅终止线程
   - 添加`isConnected()`方法检查连接状态

4. **编码支持**
   - 使用UTF-8编码进行网络通信，避免中文乱码

5. **空指针处理**
   - 对null返回值进行处理
   - 修复无限循环问题

### 2.3 UI安全修复

#### ChessPanel.java
1. **中文乱码修复**：修复所有按钮和标签的中文显示问题
2. **复盘功能安全**：
   - 使用`Model.getInstance().getList()`替代直接访问`Model.list`
   - 使用`SwingUtilities.invokeLater()`确保UI更新在EDT线程执行
   - 移除不必要的import和注释

#### Chatpanl.java
1. **中文乱码修复**：修复按钮和标签的中文显示
2. **访问控制**：将`readboard`从`public`改为`private`
3. **UI安全**：设置`readboard.setEditable(false)`，防止用户修改
4. **线程安全**：添加`appendMessage()`方法，使用`SwingUtilities.invokeLater()`更新UI

#### Control.java
1. **中文乱码修复**：修复所有对话框和提示信息的中文显示
2. **悔棋逻辑安全**：
   - 添加边界检查，避免空列表异常
   - 添加友好的错误提示
   - 完善网络模式下的悔棋逻辑

### 2.4 线程安全修复
1. **Swing EDT规范**：
   - Main.java中使用`SwingUtilities.invokeLater()`启动UI
   - 所有跨线程UI更新使用`SwingUtilities.invokeLater()`
   - 移除Chatpanl中不必要的线程
