# 五子棋游戏界面优化与聊天表情功能说明文档

## 一、项目概述

本项目是一个基于Java Swing开发的五子棋对战游戏，支持本地模式和网络对战模式。本次优化主要包括两个方面：
1. **聊天表情功能**：为聊天窗口添加表情选择和发送功能
2. **界面美化**：对棋子、棋盘、聊天窗口、按钮等进行全面的视觉优化

---

## 二、聊天表情功能

### 2.1 功能介绍

## 三、界面美化说明

### 3.1 整体布局优化

#### 主窗口 (Main.java)
- **新增背景面板**：`BackgroundPanel` 类统一管理背景图片
- **背景图片缩放**：使用平滑缩放算法确保背景图片始终覆盖整个窗口
- **渐变背景备选**：当背景图片加载失败时，自动使用棕褐色渐变背景
- **窗口优化**：
  - 窗口大小调整为 1000x700
  - 窗口标题新增图标 🎮
  - 窗口居中显示

### 3.2 棋盘美化 (ChessPanel.java)

#### 棋盘背景
- **双层边框设计**：
  - 外层圆角深棕色边框
  - 内层木纹色渐变背景
- **渐变填充**：使用 `GradientPaint` 实现木纹质感
- **双层内边框**：增强立体感

#### 棋盘线条
- **线条颜色**：深棕色 (#8B691E)
- **线宽优化**：1.2px 线宽
- **星位点**：标准五子棋9个星位点（天元+8个边星）

#### 棋子美化
- **黑白棋子均使用渐变填充**：
  - **黑棋**：深灰到纯黑的径向渐变，带白色高光
  - **白棋**：纯白到浅灰的径向渐变，带白色高光
- **立体效果**：
  - 阴影偏移 (+3, +3)
  - 高光亮点（左上1/3位置）
  - 轮廓描边
- **最后一步标记**：
  - 最新放置的棋子带红色半透明圆环
  - 便于识别当前落子位置

#### 按钮美化
- **配色方案**：深棕色背景 + 米白色文字
- **悬停效果**：鼠标悬停时颜色变浅
- **按下效果**：鼠标按下时颜色加深
- **圆角边框**：2px 圆角边框
- **按钮位置**：棋盘上方横向排列

### 3.3 聊天窗口美化 (Chatpanl.java)

## 五、使用说明

### 5.1 运行游戏

1. 确保Java环境已安装（JDK 8或更高版本）
2. 项目目录结构：
   ```
   Fivechese/
   ├── src/          # 源代码
   ├── bin/          # 编译输出
   ├── painting/     # 图片资源
   │   ├── view.jpg  # 主背景图
   │   └── R-C.jpg   # 聊天背景图
   └── music/        # 音乐资源
   ```

3. 编译运行：
   ```bash
   # 编译
   javac -d bin src/five/edu/cn/*.java
   
   # 运行
   java -cp bin five.edu.cn.Main
   ```

### 5.2 游戏操作

#### 本地模式
1. 点击"开始游戏"或"重新开始"
2. 选择"本地模式"
3. 选择棋子颜色（黑棋先手）
4. 点击棋盘交叉点落子

#### 网络对战模式
1. **创建房间**：
   - 输入用户名
   - 输入端口号（默认8900）
   - 点击"🏠 创建房间"
   
2. **加入房间**：
   - 输入用户名
   - 输入服务器IP（创建房间者的IP）
   - 输入端口号
   - 点击"🚪 加入房间"

### 5.3 聊天功能

1. 在右侧聊天窗口输入消息
2. 点击"😊"按钮选择表情
3. 点击"发送"按钮或按Enter键发送
4. 消息会显示在聊天记录中，格式为 `[用户名]: 消息`

### 5.4 游戏按钮功能

| 按钮 | 功能 |
|-----|------|
| 悔棋 | 撤销最后一步（网络模式需等待对手落子后） |
| 重新开始 | 清空棋盘，重新选择模式和颜色 |
| 开始游戏 | 开始新游戏 |
| 复盘 | 自动回放历史棋局（每秒一步） |
| 退出游戏 | 关闭程序 |

## 六、技术实现细节

### 6.1 绘图优化

- **抗锯齿**：使用 `RenderingHints.KEY_ANTIALIASING`
- **双线性插值**：`KEY_INTERPOLATION = VALUE_INTERPOLATION_BICUBIC`
- **高质量渲染**：`KEY_RENDERING = VALUE_RENDER_QUALITY`

### 6.2 渐变效果

```java
// 棋子渐变示例
GradientPaint gradient = new GradientPaint(
    rx - r/3, ry - r/3, new Color(80, 80, 80),  // 起始色
    rx + diameter, ry + diameter, new Color(10, 10, 10)  // 结束色
);
g2d.setPaint(gradient);
g2d.fillOval(rx, ry, diameter, diameter);
```

### 6.3 半透明效果

```java
// 半透明背景
new Color(255, 255, 240, 230)  // alpha值230，约90%不透明
```

## 七、注意事项

1. **图片路径**：确保 `painting/` 目录在运行时的工作目录下
2. **字体支持**：表情显示需要系统支持Unicode表情字体
3. **JDK版本**：建议使用JDK 8或更高版本以获得最佳渲染效果
4. **网络模式**：确保防火墙允许指定端口的通信
